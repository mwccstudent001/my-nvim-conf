**Important**
*This repository is not intended to be installed, it is informational only.*
*If config files are provided they should be placed in the proper system locations manually*

I have only learned this information in the context of a fresh install of Neovim on a Linux system. 
I know the file structure on MacOS is similar to Linux, but there may be filestructure differences that I'm not aware of. 

In order to customize a default Neovim installation you first need to make sure you have an 'nvim' folder in your '.conf/' folder.
Within that folder you need to make an 'init.lua' file.

My 'init.lua' file is provided in this repository. As of writing I haven't finished adding to it but it's definitely usable as it is now.
